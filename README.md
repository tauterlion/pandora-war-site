# Pandora War Server Website

Official information website for the Pandora War Server.

## Read these first

- `AGENTS.md` — standing instructions for Codex
- `PANDORA_BRIEF.md` — product, visual, motion, and interaction direction
- `CONTENT.md` — current factual server/game content
- `references/` — supporting source material, including the player-facing DOCX once added

## Recommended first Codex task

Ask Codex to read all three Markdown files before coding.

The first implementation pass should focus on the design foundation rather than finishing every page:

- project scaffold / frontend stack
- global layout and navigation
- typography and color system
- animated topographic background
- homepage hero
- base button / hover behavior
- responsive behavior
- reduced-motion support
- clean content/data organization

Do not ask it to invent missing factions, players, screenshots, or live server data.
